# Site do Centro Acadêmico

Sistema web desenvolvido para o Centro Acadêmico, com o objetivo de centralizar informações, eventos e facilitar a comunicação entre os estudantes e a gestão do CA.

## Sobre o Projeto

O Site do Centro Acadêmico foi criado para oferecer uma plataforma intuitiva e responsiva, permitindo que os alunos tenham acesso rápido às principais informações do Centro Acadêmico .

Entre os principais objetivos estão:

- Divulgação de eventos;
- Publicação de notícias;
- Apresentação da equipe do Centro Acadêmico;
- Canal de contato;
- Área administrativa para gerenciamento do conteúdo.

## Como executar o projeto

Clone o repositório

Copie o .env.sample e renomeie para .env

Rode o projeto usando:

```bash
docker compose up
```

O sistema ficará disponível em:
http://localhost:3000

Para fechar o programa:

```bash
docker compose down -v
```
